# Tailor Workspace and PDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved job-input, evidence-backed resume review, A4 preview, and PDF download workflow on the existing Tailor page.

**Architecture:** Extend the existing tailoring contract so a generated resume contains a canonical structured snapshot derived from verified profile facts and stable review patches. Render the snapshot through a shared frontend A4 component, and export a server-rendered equivalent with Playwright using the same physical template tokens. Add safe public job URL extraction with an explicit editable-description confirmation step.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, TanStack Query, Zod, FastAPI, Pydantic, SQLAlchemy/PostgreSQL, HTTPX, Jinja2, Playwright, Pytest, Vitest.

---

## File structure

- `backend/app/models/job.py`: URL extraction request/response contracts.
- `backend/app/jobs/url_extractor.py`: SSRF-safe URL validation, fetching, and readable-text extraction.
- `backend/app/api/jobs.py`: URL extraction endpoint.
- `backend/app/models/tailoring.py`: canonical resume, keywords, and reviewed-document response contracts.
- `backend/app/tailoring/resume_builder.py`: deterministic resume snapshot construction and patch application.
- `backend/app/tailoring/pdf_renderer.py`: template HTML and Playwright PDF rendering.
- `backend/app/tailoring/agent_pipeline.py`: persist canonical snapshot and return complete review state.
- `backend/app/api/tailoring.py`: retrieve reviewed resume and download PDF.
- `backend/templates/basic-a4-resume.html.j2`: server print template.
- `backend/tests/test_job_url_extractor.py`: URL safety and extraction tests.
- `backend/tests/test_tailored_resume_builder.py`: deterministic snapshot/patch tests.
- `webapp/src/schemas/tailoring.ts`: frontend contracts.
- `webapp/src/api/jobs.ts`: URL extraction client.
- `webapp/src/api/tailoring.ts`: reviewed resume and PDF clients.
- `webapp/src/features/tailor/job-description-editor.tsx`: full-height plain-text document editor.
- `webapp/src/features/tailor/basic-a4-resume.tsx`: A4 resume renderer and review overlays.
- `webapp/src/features/tailor/change-review.tsx`: filters, change cards, and keyword view.
- `webapp/src/pages/tailor.tsx`: state orchestration and responsive two-pane workspace.
- `webapp/src/styles/globals.css`: Tailor workspace, editor, A4, print, and responsive styles.
- `webapp/src/features/tailor/tailor-ui.test.tsx`: editor and renderer behavior.
